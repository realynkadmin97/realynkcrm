## Issues and solutions

**The cleaner was a plain table.** Joan sent a screenshot. The page had a big title, text boxes, and Remove beside every header. Solution: rebuild `/clean` as the Lead Enrichment sheet, with client tabs, column letters, row numbers, and the same toolbar. Commit `58c3731`.

**The column menu would not close.** It stayed over the cells after a click, Escape, and clicking the header again. Solution: listen for a click outside and for Escape, and toggle the same header shut. Commit `2f779ad`.

**The sheet crashed after the menu work.** The page imported the database module into the browser, and that pulled in Postgres. Solution: keep prompts and freeze data in `src/lib/sheet-meta.ts`, which the browser can load. The database stays on the server.

**Supabase sign-in returned `Unrecognized client_id`.** Creating the project was fine. Cursor was reusing an old OAuth client id that Supabase no longer accepts. Solution: remove the plugin, quit Cursor, connect again. By 23:05 the session was signed in to project Realynk CRM in Tokyo, status healthy.

**Several connect prompts were closed before they finished.** Nothing was wired during those attempts. The successful sign-in is the one that can see the project.
